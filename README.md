## 🔨 What I'm Building

**🕶️ [Shadow](https://shadow.anuragwagh.com)** — A stealth window invisible to screen recording and screen sharing. Kernel-level privacy for people who actually need it. Big Tech doesn't care about this use case. I do.

**📚 [PrepGrind](https://prepgrind.com)** — Competitive exam prep platform. 750+ users, 20 paying, 2M+ Google impressions. Built end-to-end, solo. Every line of code, every design decision, every support reply — me.

**🧠 [Hinglish MiniLM](https://huggingface.co/anuragwagh0)** — CPU-efficient language model for Hindi-English code-switching. Because 600 million people speak this way and the NLP world mostly ignores them.

**🗣️ [Marathlish MiniLM](https://huggingface.co/anuragwagh0)** — Same idea, Marathi-English. Regional languages deserve real ML infrastructure.

**🔭 [LLM Observatory](https://obserflo.vercel.app)** — Traces LLM prompt costs and usage in real time. Built it because I was going blind on API spend.

**🛠️ [UtilX](http://utilx.app/)** — 65 micro tools across categories. The kind of thing you reach for when every other option is overkill.

**⚡ [Thought Stream](http://thoughtstream.anuragwagh.com/)** — A keyboard-first desktop app for capturing thoughts without breaking flow. Global hotkey (`Ctrl + Shift + Space`), slash-command categorization, zero mouse required. Built for deep thinkers who think faster than they can organize.

**🧬 Memory OS** — Local-first AI memory layer. Python, ChromaDB, MCP. Your AI shouldn't forget who you are every time you open a new tab.
